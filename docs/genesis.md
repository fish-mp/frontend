# Главная университета «Генезис»

Исходный макет: [Генезис — Главная · концепция](https://www.figma.com/design/2QOry45UMUZd1JETyhWHtX?node-id=265-156), Desktop 1920 × 6010. Макет прочитан через Figma Desktop Bridge. Размеры, палитра, тексты и SVG взяты из текущей концепции.

## Локальный запуск

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

На `http://127.0.0.1:5173/` открывается университет. Backend ему не требуется. Переменные подключения к backend и картам нужны существующей школе аквариумистики.

Проверить прежний сайт отдельным сервером:

```powershell
$env:VITE_SITE = 'aquarium'
npm run dev -- --host 127.0.0.1 --port 5174
```

После остановки этого сервера удалить временную переменную: `Remove-Item Env:VITE_SITE`.

## Домены и сборки

Без `VITE_SITE` главная выбирается по hostname: `fishkids.ru`, `www.fishkids.ru` и другие поддомены FishKids открывают прежнюю школу. `inco-edu.ru`, его поддомены и локальный адрес открывают университет. `VITE_SITE=university|aquarium` явно задаёт сайт для отдельной сборки и её HTML-метаданных.

Для университета:

```powershell
$env:VITE_SITE = 'university'
npm run build
```

Для школы:

```powershell
$env:VITE_SITE = 'aquarium'
npm run build
```

В Docker сохранён режим `aquarium` по умолчанию для существующего развёртывания FishKids. Сборка университета: `docker build --build-arg VITE_SITE=university -t genesis-frontend .`. Статические файлы из `dist` обслуживаются с SPA fallback на `index.html`.

Университет опубликован 1 ноября 2026 года: `https://inco-edu.ru` и `https://www.inco-edu.ru`. FishKids продолжает работать на `https://fishkids.ru` в прежнем контейнере.

На VPS университет развёрнут отдельным Compose-проектом `genesis`, контейнером `genesis-university`, с `restart: unless-stopped`. Конфигурация: `/home/desai/university/docker-compose.yaml`; порт проверки доступен только локально: `127.0.0.1:5175`. Общий Nginx направляет университетский домен на этот контейнер; API, admin и медиа школы на домене университета возвращают 404. Блоки Nginx для FishKids сохранены без изменений.

Опубликована сборка `2eceaff57ee387d8253940ef910b52aacfc7bd15`. Исходники, журнал сборки и прежняя конфигурация Nginx: `/home/desai/university/releases/2eceaff57ee387d8253940ef910b52aacfc7bd15`. Маркер версии — `/university-release.json`. `robots.txt` и `sitemap.xml` в сборке указывают на университет.

`scripts/deploy-university.sh SHA stage` собирает отдельный образ; `activate` запускает его и переключает домен с автоматическим восстановлением Nginx при неудачной проверке. Скрипт рассчитан на первичное развёртывание и повтор его активации после отката. При замене контейнера требуется перезагрузка конфигурации внешнего Nginx для обновления адреса upstream.

Для отката маршрутизации на прежний сайт скопировать содержимое `nginx.before.conf` из каталога выпуска в `/home/desai/deploy/nginx.conf`, сохранив inode файла (`cat backup > config`), затем выполнить `docker exec deploy_nginx_1 nginx -t` и `docker exec deploy_nginx_1 nginx -s reload`. SSH-пароль вводился владельцем в системный SSH-клиент и не сохранялся. Секрет `PROD_SSH_KEY` в GitHub пока неработоспособен; автоматическая выкладка через него требует исправления доступа.

Магистратура, аспирантура, ДПО, колледж и цифровая школа представлены на главной, их переходы отключены. Поддомены и страницы для них не создавались. Галактика школы аквариумистики и ссылка в подвале ведут на `https://fishkids.ru`. Все десять кнопок «Подробнее» открывают модальное окно: для готовящейся страницы — сообщение о скором появлении материалов, для школы аквариумистики — описание и кнопка перехода на её сайт.

## Структура и графика

- `src/pages/UniversityHome.vue` — главная, меню, поиск по разделам и диалоги.
- `src/data/genesis.ts` — тексты и состав карточек.
- `src/assets/css/genesis.css` — локальные токены из Figma, сетки и адаптивные стили.
- `src/components/genesis/GenesisAction.vue` — варианты кнопок из концепции.
- `src/utils/site.ts` — выбор сайта и домены.
- `public/genesis` — оригинальные SVG; временных URL Figma в приложении нет.

Имена `s1`–`s6` соответствуют разделам макета: `265:317`, `265:548`, `265:724`, `265:835`, `265:953`, `265:963`. Имена `img` внутри раздела сохранены из ответа Figma для сопоставления с экспортами. Галактики первого экрана — `s1-img3.svg`–`s1-img8.svg`; изображения карточек имеют отдельные экспорты требуемых размеров. SVG не перерисованы. Gotham Pro используется из имеющихся файлов проекта.

Шесть галактик используют компонент `GenesisGalaxy.vue` и SVG из `src/assets/genesis/galaxies`. Оригинальные контуры сохранены, но разделены на рукава, орбиты, ядро, звёздную пыль и отдельные звёзды. Вращение выполняется внутри наклонённой плоскости диска (проекция × вращение × обратная проекция); ракурс галактики остаётся неподвижным. При наведении или фокусе независимо вращаются рукава и орбиты, пульсирует ядро и мерцают звёзды. Вне взаимодействия анимации приостановлены. Идентификаторы градиентов уникальны для каждой галактики. Появление секций запускается однократно через IntersectionObserver. `prefers-reduced-motion` отключает движения. Кнопка с глазом и переключение повышенной контрастности убраны по запросу владельца.

У университета собственный layout. Страницы и layout FishKids загружаются отдельно. Первый экран университета не отправляет запросов к backend, Яндекс Картам или счётчику FishKids. Вход, сведения и документы университета, ещё не предоставленные для публикации, не подключены к backend; интерфейс сообщает об их подготовке. Форма подачи заявления не создавалась.

## Проверки

```powershell
npm run build
npm run test:site
npm run test:auth
npm run test:aquarium
```

Для визуальной проверки: 1920 px (исходный макет), 1440 px, 768 px и 390 px. Проверить меню, поиск, Escape и возврат фокуса, якорные ссылки, отсутствие горизонтальной прокрутки, анимацию галактик и отключённые направления.

## Улучшения главной

Шапка закреплена при прокрутке и после 80 px становится компактнее. Её место в потоке сохраняется, а якорные переходы учитывают высоту шапки. На телефонах названия галактик и значения параметров обучения имеют размер 14 px; галактики расположены в два столбца, параметры — в два столбца с отдельной строкой для набора. Быстрые карточки институтов выстроены в один столбец, чтобы длинные названия оставались читаемыми.

Все три карточки будущих публикаций помечены «Анонс». Даты не придуманы; прежняя подпись «Дата уточняется» убрана. Кнопка «Об анонсе» объясняет, что материал готовится к публикации.

IntersectionObserver приостанавливает слои галактик за пределами экрана, даже если на них остался фокус. Page Visibility API приостанавливает анимации при скрытой вкладке. Обработчики и наблюдатели отключаются при уходе со страницы.

В подвале единый блок «Обратная связь»: `support@inco-edu.ru`, +7 (916) 435-40-10, пн–пт 09:30–18:30. По запросу владельца сохранены телефон и часы работы из существующего `src/components/Footer.vue`; отдельные название и почта школы убраны из контактов университета. Основной текст и заголовки колонок имеют единый размер 14 px и межстрочный интервал. На телефонах навигация расположена в двух столбцах, контакты — отдельной строкой. Блок документов FishKids убран из футера университета; документы остаются на сайте школы.

Для обратной связи по запросу владельца указан `support@inco-edu.ru` с mailto-ссылкой и темой письма. Адрес хранится в `src/data/genesis.ts`; создание ящика и настройка доставки писем выполняются отдельно на почтовом сервисе домена. Работоспособность ящика не подтверждена.

Переключатель RU / EN переводит главную университета, меню, поиск, подсказки и диалоги. Английские тексты хранятся в `src/data/genesis.en.ts`, выбор языка — в `localStorage` (`genesis-language`). Меняются атрибут `lang` и заголовок вкладки. Переключатель доступен на телефонах; сайт FishKids сохраняет собственный интерфейс.
