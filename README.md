# Цифровая школа

Vue 3 + TypeScript + Vite, Vue Router, Pinia, SCSS.

## Запуск

```sh
npm ci
npm run dev
```

Для запросов к бэкенду скопируйте `.env.example` в `.env` и укажите `VITE_BACKEND_URL`. Перезапустите Vite после изменения переменных. Без настройки бэкенда новости, мероприятия и магазин основного сайта показывают примеры из макета. Авторизация и данные школы аквариумистики требуют бэкенд.

```sh
npm run build
npm run preview
```

## Основные адреса

- `/` — главная «Цифровой школы», семь направлений, переключатель направлений и популярные курсы.
- `/news`, `/news/:id` — новости и отдельный материал.
- `/events`, `/events/:id` — мероприятия и отдельное событие.
- `/aquarium` — существующая главная «АкваВселенной».
- `/aquarium/news`, `/aquarium/events` — прежние списки материалов в оформлении аквариумистики.
- `/shop` — магазин основного сайта с поиском, категориями и сортировкой.
- `/aquarium/shop` — существующий магазин аквариумистики.
- `/courses`, `/my-courses`, `/cart`, `/checkout`, `/profile` — существующие страницы аквариумистики.

Пока работает только школа аквариумистики. Остальные шесть направлений обозначены «Скоро откроется» и не ведут на несуществующие страницы. Названия, возрастные группы и статусы задаются в `src/data/directions.ts`; для запуска раздела добавьте ему `to` и соответствующий маршрут.

Блок «Популярные курсы» содержит 12 статических примеров из макета, без подключения к API и записи на курс. На узких экранах карточки прокручиваются горизонтально. Под ним — шесть портретов преподавателей с именами-заглушками из макета.

Первый экран содержит семь интерактивных SVG-планет по направлениям школы. При наведении и фокусе с клавиатуры поверхность вращается. Аквариумистика ведёт на `/aquarium`, остальные планеты — на карточки готовящихся направлений. На телефоне планеты можно листать горизонтально; при `prefers-reduced-motion` анимации отключаются.

При настроенном API новости и мероприятия основного сайта используют существующие `/api/news/` и `/api/events/`; эти материалы относятся к школе аквариумистики. Разделения данных по новым направлениям в API пока нет. Календарь фильтрует мероприятия по дню и переключает месяцы. Демонстрационные товары не оформляют заказы, подписка и запись на демонстрационные события пока недоступны.

Оформление основного сайта отделено от существующего через `route.meta.portal`, `PortalLayout.vue` и `digital-school.scss`. SVG первого экрана и логотип сохранены локально из Figma; временных URL Figma в приложении нет.
